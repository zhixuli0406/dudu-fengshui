# 形勢派／陽宅室內格局禁忌 — 可程式化規則庫

> **調研日期**：2026-09-05
> **用途**：供 `dudu-fengshui` Web 端「風水分析與建議」程式使用。內局規則以「能從平面圖幾何自動判定」為設計目標；外局規則以「問卷勾選」形式收集。
> **方法**：WebSearch + WebFetch 查一手來源，每條規則附來源 URL。凡來源未給出的數值，一律標記 `[程式預設值，未有來源]`。
> **重要聲明**：本文件是**民俗知識的資料化整理**，不是對風水有效性的科學背書。多數條目在不同流派間存在分歧，已在 §8 逐一列出。程式呈現時應明確告知使用者這是傳統民俗建議。

## 0.1 幾何資料模型（所有規則的共同前提）

判定引擎需要平面圖提供以下物件，長度單位一律**公尺（m）**：

| 物件 | 必要欄位 |
|---|---|
| `Unit`（整戶） | 外框多邊形 `outline`、`level`（樓層）、`north_bearing`（正北方位角，可選） |
| `Room` | 多邊形 `polygon`、`type`（玄關/客廳/餐廳/主臥/次臥/兒童房/書房/廚房/廁所/樓梯間/陽台/騎樓/儲藏/神明廳）、`level`、`area` |
| `Wall` | 線段 `seg`、`thickness`、`side_a_room_id` / `side_b_room_id`、`is_structural` |
| `Door` | 牆上線段 `opening`、`hinge_point`、`swing_dir`（內開/外開/滑門）、`swing_sector`（開啟掃掠扇形）、`door_type`（大門/房門/廁所門/廚房門/後門/陽台門） |
| `Window` | 牆上線段、`sill_h`（窗台高）、`head_h`（窗頂高） |
| `Beam` | 天花板上的矩形投影（OBB）、`depth`（樑下垂深度） |
| `Column` | 柱斷面多邊形（含 90° 外角） |
| `Fixture` | `type`（爐灶/水槽/冰箱/馬桶/洗手台/浴缸/神桌/沙發/餐桌/床/書桌/鏡/吊燈/冷氣/樓梯/收銀台）、水平投影矩形（含旋轉角）、`facing`（正面法線）、`mount_h` |
| `Bed` | 矩形 + 明確標記 `head_edge` / `foot_edge` / `side_edges`、`mattress_h`、`frame_h` |
| `Desk` | 矩形 + `seat_point`（座位點）+ `facing`（使用者面向向量） |
| 樓層關係 | 同一 (x, y) 在 `level ± 1` 的 Room type（樓上樓下判定） |

**共用輔助定義**

| 名稱 | 定義 | 依據 |
|---|---|---|
| `clear_los(A, B)`（視線通暢） | A→B 的線段不與任何高度 ≥ 0.90 m 的遮擋物（牆、屏風、高櫃、過膝門簾）相交 | `[程式預設值，未有來源]`；來源普遍只說「過膝門簾／屏風」 |
| `overlap_ratio(a, b)` | 兩線段投影到同一直線後的重疊長度 ÷ 較短邊長度 | — |
| `facing_each_other(A, B, θ)` | `angle(n_A, −n_B) < θ` 且互相投影重疊 > 0 | θ 預設 30° `[程式預設值，未有來源]` |
| `center_palace(unit)`（中宮） | 整戶外框的最小外接矩形 3×3 等分後的中央格；不規則平面改用「外框重心 ± 邊長 1/6」 | 九宮法為傳統通用作法 |
| `sector8(unit, bearing)` | 以宅心為原點的 8 個 45° 扇區（北 337.5–22.5、東北 22.5–67.5、東 67.5–112.5、東南 112.5–157.5、南 157.5–202.5、西南 202.5–247.5、西 247.5–292.5、西北 292.5–337.5） | 標準二十四山簡化 |

## 1. 外局（周邊環境）— 問卷題組

外局幾乎無法從室內平面圖判定，需以問卷收集。以下每題可直接對映成一個 UI 元件。

> 名稱與化解法主要參照 Ailan 風水研究室〈外在煞氣 126 種〉分類體系（https://www.ailan.idv.tw/sah.html ）與大紀元〈開運風水 DIY⑤ 外在的煞氣〉上／中／下三篇。

### 1.1 問卷題組（40 題）

> 每題的 `選項` 直接對映 UI；`severity` 為該項命中最嚴重選項時的等級。

**查表演算法（程式實作）**

```
def wen_gong(length_cm, cycle=43.2):
    x = length_cm % cycle              # 取餘數落在循環內
    idx = int(x // (cycle / 8))        # 0..7 → 財病離義官劫害本
    sub = int((x % (cycle / 8)) // (cycle / 32))   # 0..3 → 四細分
    return WORDS[idx], SUBS[idx][sub], LUCK[idx]
```

- 「神明廳宜坐北朝南」
- 「廚房忌正南（火上加火）」

### 6.5 判定引擎的建議執行順序

1. **前處理**：房間分類 → 牆體鄰接圖 → 門開啟掃掠扇形 → 樑投影帶 → 中宮九宮格 → 樓層投影表 → 動線圖（房間為節點、門為邊）。
2. **無方位依賴的規則**（§2 絕大多數）先跑，這些只需平面圖。
3. **需要 `north_bearing`** 的規則（`kitchen_northwest`、`toilet_ghost_gate`、`bed_head_facing_west`、`child_room_position`、§4 全部）在使用者提供坐向後才跑，並在報告中分開一區。
4. **外局問卷**（§1）獨立計分，**不要與內局合併成單一分數**——外局的流派分歧遠大於內局。
5. **樓層五行**（§1.4）標為「民俗參考」，不計入總分。
6. 同一現象可能被多條規則命中（例：地下停車場出入口正對同時命中 `open_mouth_garage` 與 `road_rush`），需設互斥或去重權重。

### 8.2 「這條到底算不算煞」— 流派實質衝突

| 議題 | 正方 | 反方 |
|---|---|---|
| **開門見灶** | 《陽宅三要》「開門見灶，錢財多耗」（100室內設計轉引） | 幸福空間受訪命理師：古代大灶熱氣量大才成問題，「現代瓦斯爐熱氣量遠小於古灶，**開門見灶並非太大問題**」；真正的問題是走道過窄（建議 ≥1.8 m）與雜物堆積 |
| **樑壓床／樑壓灶** | 多數來源論凶，並分部位對應身體部位 | 風水師吳尚易（幸福空間）：古代禁忌源於「怕樑斷了人被壓到」，「現在的建築早已不同…如今的樑根本不會有這種問題」，並批評貼紅紙、掛簫等化解法無根據。另有主張樑壓灶應改判「樑是否壓在**站立操作者頭頂**」而非爐具本體 |
| **鏡子對床** | 傳統派：鏡子屬陰，造成煞氣 | 吳尚易：心理因素（夜間昏暗光線下被自己倒影驚嚇），「**影響範圍其實只有 50 公分左右**」，空間足夠時「鏡子愛怎麼擺就怎麼擺」 |
| **電視對床（輻射說）** | 傳統：電視輻射傷身 | 班尼斯**自行否定**：「現代電視輻射已符合安全標準；主要問題是減少家庭成員互動」 |
| **包樑算不算化解** | 設計端（100室內設計、狸樂聚、Toby）：造型天花包覆即化解 | 傳統派：樑體實存，包起來只是遮住視覺，仍需家具移位或法器。Toby 另提醒樓底低時全面假天花反而更壓迫 |
| **大門正對樓梯** | 幸福空間：不分上下一律論凶 | ETtoday（楊尚義）：向上樓梯「反倒象徵步步高升」不算煞 |
| **反弓煞** | 蘇民峰：「無論離樓宇遠近都作凶論」 | 住展（盧尚）：舉南崁溪反弓正對長榮海運大樓「旺了幾十年獲利極可觀」為反例 |
| **壁刀煞／厝角沖** | Ailan、多數商業站：正對即凶 | 住展：「如果你的樓房是十餘層高、鋼筋水泥結構，則用不著怕外部物事的沖射」；幸福空間：「絕大多數被認定為壁刀的情況，其實都不會造成影響」 |
| **廟宇** | Ailan、幸福空間：正對即凶 | 住展：只看相對高度——「**彼高我低，我居劣勢；我高彼低，則彼雖寺廟亦不足為患**」 |
| **墳場靈骨塔** | 陰煞之地，主病痛意志消沉 | 住展：「靈骨塔旁也有人發財，卻從未遇見鬼魅……嫌惡事項為一般世俗的概念，對房價有影響，但風水方面的吉凶效應不見得會出現」 |
| **學校** | 住展：正對校園「文昌煥然，加分極多」 | 陳定邦：「雖無煞但無益」，白天人氣旺放學後驟空，「晚上完全沒有人氣就自然容易聚陰」 |

### 8.4 調研過程的技術限制（誠實揭露）

- **WebSearch 配額在本 session 用罄（200/200）**。後半段全靠 WebFetch 直抓、站內搜尋、Big5 轉碼 curl 補足。
- DuckDuckGo、Mojeek、Ecosia、Startpage、Yandex、Qwant、SearXNG 公開實例在本環境全部被反爬阻擋；Brave 約 10 次後被封；Yahoo 抓幾次後回 500；Bing 可通但返回的是字典類無關結果。
- 因此**「查無來源」的正確理解是「在本次可用的搜尋手段下查不到」，不等於「一定不存在」**。
- **建議的補查清單**（另開 session 用完整 WebSearch 配額）：室內長廊煞、天花板淨高門檻、地板高低差、樑壓神位、店面／收銀台風水專文、《陽宅十書》《陽宅三要》電子文本、完整的房間×方位矩陣。

### 8.5 產品化建議

1. **分軌計分**：形勢派（§2 內局）／理氣派（§4 方位）／外局問卷（§1）三者**分開計分、分開呈現**，因為三者的結論可能互相矛盾。
2. **提供「傳統嚴格／現代寬鬆」開關**：樑壓床、鏡子對床、開門見灶這三條，具名風水師本人在受訪中否定其中一部分，寬鬆模式應把它們降級或關閉。
3. **化解建議的排序原則**：本文件所有 `remedy` 陣列都已依「①調整擺設 → ②硬體改造（屏風／櫃體／包樑／門簾）→ ③植物 → ④法器（五帝錢／葫蘆／山海鎮／麒麟）」排序。**建議 UI 預設只顯示前兩級**，法器類收在「傳統做法」摺疊區——法器類來源多半來自販售法器的網站（見 §7.2 的利益衝突註記）。
