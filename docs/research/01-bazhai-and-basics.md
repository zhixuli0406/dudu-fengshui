## 1. 基礎體系

### 1.1 陰陽

陰陽的核心定義：性質相反相成、互相對立又互相依賴、恆久持續的兩種力量。《周易・繫辭傳》：「一陰一陽之謂道。」

| 屬性面向 | 陽 | 陰 |
|---|---|---|
| 質性 | 清輕、光明、炎熱 | 濁重、晦冥、寒冷 |
| 動靜 | 好動、剛健、外向 | 沉靜、柔順、內斂 |
| 方位 | 南方、上方 | 北方、下方 |
| 數 | 奇數（1,3,5,7,9） | 偶數（2,4,6,8,10） |
| 生殺 | 生長、生養 | 收斂、肅殺 |
| 建築對應 | 客廳、書房、玄關、明亮開放空間 | 臥室、儲藏室、廁所、幽暗封閉空間 |

四個基本關係（程式可作為「平衡度」評分的理論依據）：

| 關係 | 說明 | 出處引文 |
|---|---|---|
| 對立制約 | 陰陽各有不同性質，相互制衡 | 《春秋繁露》：「陽氣暖而陰氣寒，陽氣予而陰氣奪」 |
| 互根互用 | 陽中有陰、陰中有陽，相互依存 | 太極圖黑白兩點 |
| 消長平衡 | 動態平衡 | 「春夏陽多而陰少，秋冬陽少而陰多」 |
| 相互轉化 | 極則反 | 《周易・繫辭傳》：「動極而靜，靜而生陰；靜極復動」 |

來源：https://zh.wikipedia.org/zh-tw/%E9%99%B0%E9%99%BD （維基百科）

> 程式應用提示：陰陽用於「空間屬性 vs 用途」的合理性檢查（例：臥室屬陰、不宜過度明亮開放；客廳屬陽、不宜幽暗）。此為輔助建議，非八宅派核心計算。

### 1.2 五行完整關係表

#### 1.2.1 相生 / 相剋（基礎二關係）

- **相生**：木生火，火生土，土生金，金生水，水生木。
- **相剋**：木剋土，土剋水，水剋火，火剋金，金剋木。

來源：https://zh.wikipedia.org/zh-tw/%E4%BA%94%E8%A1%8C （維基百科）

#### 1.2.2 五種完整關係（生／剋／洩／耗／比和）

風水與命理實務用的是「以我為主」的五種關係，這是程式做五行評分的核心：

| 關係 | 定義（以「我」為主體） | 對我的作用 | 木的例子 | 火的例子 | 土的例子 | 金的例子 | 水的例子 |
|---|---|---|---|---|---|---|---|
| **生（生我）** | 生我者 | 增強（＋強） | 水生木 → 我＝木，生我＝水 | 木 | 火 | 土 | 金 |
| **比和（幫／同我）** | 與我同五行 | 增強（＋中） | 木 | 火 | 土 | 金 | 水 |
| **洩（我生）** | 我生者，洩我之氣 | 削弱（−中） | 木生火 → 洩者＝火 | 土 | 金 | 水 | 木 |
| **耗（我剋）** | 我剋者，耗我之力 | 削弱（−弱） | 木剋土 → 耗者＝土 | 金 | 水 | 木 | 火 |
| **剋（剋我）** | 剋我者 | 削弱（−強） | 金剋木 → 剋者＝金 | 水 | 木 | 火 | 土 |

原文引用（八字命理，風水沿用同一套關係）：
「克：克日干的元素／泄：日干生旺其他元素（消耗我的力量）／耗：日干所克的元素（反過來耗損我）／生：生旺日干元素／帮：和日干相同的元素」
「如果我日干為火的話，『克』：水元素（水克火），『泄』：土元素（火生土），『耗』：金元素（火克金）」
— https://www.163.com/dy/article/HAMVI42O0553APWV.html （一般部落格／自媒體，但定義與各家一致）

交叉參考：https://vocus.cc/article/60c3171dfd897800013151f2 （同我／我生／我剋／剋我／生我 五分法）、https://www.masterso.com/classroom/classroom2_1_5.php （蘇民峰命理風水網站，專業站）

#### 1.2.3 相乘 / 相侮（失衡的兩種病態關係）

| 關係 | 定義 | 順序 |
|---|---|---|
| 相乘 | 「倍克」，加倍克制（剋太過） | 木乘土、土乘水、水乘火、火乘金、金乘木 |
| 相侮 | 「反克」，反過來克制（被剋者太強） | 木侮金、金侮火、火侮水、水侮土、土侮木 |

來源：https://baike.baidu.com/item/%E4%BA%94%E8%A1%8C%E7%94%9F%E5%85%8B/8927278 （百度百科）、https://zhuanlan.zhihu.com/p/508828022

### 1.4 洛書九宮與河圖

#### 2.1.5 統一通式（**本程式採用**，跨世紀免分支）

```
男命卦 = ((11 − Y) mod 9)，結果 0 則取 9
女命卦 = ((Y − 5) mod 9)，結果 0 則取 9
```

```
FUNCTION group_of(gua) -> string:
    RETURN "東四命" IF gua IN EAST_GROUP ELSE "西四命"
```

### 2.2 宅卦（宅命）判定

#### 2.2.1 以「坐山」定宅卦

**八宅派以坐山（坐方）定宅卦，不以朝向。** 但實務入口多半反過來：先量大門朝向，再反推坐山。

> 「先看大門所向為何度，然後**以坐方為宅主卦**」— https://fusuibeginnercom.wordpress.com/2018/10/17/ （Feng Shui Beginner，港）

#### 2.2.2 坐與向的程式換算

```
sitting = (facing + 180) % 360
gua     = ['坎','艮','震','巽','離','坤','兌','乾'][ floor(((sitting + 22.5) % 360) / 45) ]
```

#### 2.4.2 歌訣讀法（最容易搞錯的點，已確證）

**方位排列順序 ＝ 乾 → 坎 → 艮 → 震 → 巽 → 離 → 坤 → 兌（循環）**
這串順序在後天八卦盤上就是**從西北起、順時針走一圈**：

| 卦 | 乾 | 坎 | 艮 | 震 | 巽 | 離 | 坤 | 兌 |
|---|---|---|---|---|---|---|---|---|
| 方位 | 西北 | 北 | 東北 | 東 | 東南 | 南 | 西南 | 西 |

**兩條規則**：
1. 句首那個字是**宅卦本身，即伏位**，歌訣不另給星名（所以每句只有 7 個星字）。
2. 其後 7 字，**從該卦的「下一位」開始**，依上表順時針序**輪轉**——不是每句都從乾起算。

**實例（乾）**：乾＝伏位 → 坎＝**六**煞 → 艮＝**天**醫 → 震＝**五**鬼 → 巽＝**禍**害 → 離＝**絕**命 → 坤＝**延**年 → 兌＝**生**氣
**實例（離，輪轉最明顯）**：離＝伏位 → 坤＝**六**煞 → 兌＝**五**鬼 → 乾＝**絕**命 → 坎＝**延**年 → 艮＝**禍**害 → 震＝**生**氣 → 巽＝**天**醫

讀法佐證：陳益峰文明言「按顺时针的顺序」依次排列；〈教你速记阳宅风水大游年歌〉述「按顺时针逐一比较八个方位」（https://www.sohu.com/a/412208907_100084723 ）；郭䇾風水文化站記「按照乾、坎、艮、震、巽、離、坤、兌後天的八卦方位成歌」（http://fuxi.fude99.cn/index.php/2023/07/08/大遊年歌-八宅風水精華及圖例/ ）。

⚠️ **傳抄訛誤訂正**：部分轉抄版把坎句寫成「坎五天生延絕禍**五**」，其中「五」重複、「六」缺席，**違反「每句七星各一次」的校驗**。正確應作「坎五天生延絕禍**六**」——本文的兩套獨立推導皆得此結果。

### 2.5 陽宅三要「門、主、灶」

出自清・**趙九峰《陽宅三要》**（乾隆年間成書）。

| 要素 | 定義 | 註 |
|---|---|---|
| **門** | 人出入之路（大門／主要出入口） | 判斷起點 |
| **主** | 住宅主人停留最久之處；當代多指主臥室 | **[有分歧－三說]** 另有解為全宅最高大之主房、宅之坐山；《陽宅集成》另立**順位法**，見下 |
| **灶** | 烹飪之處 | **兩書測的構件不同，見 §2.6.2** |

**判斷順序與原則**（多來源一致）：
1. 先定門，次定主，再定灶。
2. 三者五行**相生或比和則吉，相剋則凶**。
3. 最佳格局為循環相生：**門生主 → 主生灶 → 灶生門**。
4. **三者須同屬一宅**（同屬東四或同屬西四）：「门、主、灶三者属同一宅者吉，不属于同一宅者不吉」。

⚠️ **《陽宅三要》起伏位用「門上」，與《八宅明鏡》的「坐山」不同**（見 §2.2.3）。原文：「看大門在某宮某字，或屬東四宅，或屬西四宅，**則門即定矣**」— https://fs.yi958.com/Article_11728.html

來源：https://moritaisei168.com/column/yotaku-sanyou-monshusou.html （日文站引趙九峰原著）、https://www.yixiansheng.com/article/4556.html 、https://fs.yi958.com/Article_11728.html

**《陽宅集成》的順位法**（第三種說法）：
> 卷一：「**未立香火，以灶為主；如無坐灶，以床為主；主者，中宮之位也。**」
> — https://www.ichingtrilogy.com/post/yang-zhai-ji-cheng-01-1/ （古籍全文）

即認定順位為 **香火（神位）→ 灶 → 床**，與《陽宅三要》的「高大者即是主」路線不同。

#### 2.6.2 灶位「座凶向吉」——**已找到原文出處，原假設成立**

> 本項在調研中段一度被標為「查無出處且多數來源相反」。取得《八宅明鏡》全文後**已確證有原文依據**，此處為修正後的結論。

四段原文全部出自 https://fs.qqqs.org/fssj/396.html ：

1. **總則**：「**四吉星宜開門、立向、安床、灶向，不宜灶廁。凶星忌宅向、開門，反宜廁所、灶座、煙囪、磨房碓碾以鎮其凶，不但無災，反可改福。**」
2. **分工**：「**灶座論方不論向，灶口論向不論方。**」
3. **灶座壓凶的逐星應驗**：「安本命凶方則吉，**壓本命吉方則凶**，屢試屢驗……壓生氣方應主墮胎、無子……**壓絕命方應主康壽添丁**……**壓五鬼方應主永無火盜、發財、田畜大旺**。」
4. **火口向吉**：「**火門者，鍋底納柴燒火之口，得向吉方，發福甚速**，期月之間即驗。」

#### 與《陽宅三要》「灶宜安三吉方」的矛盾——**已解開**

兩書看似衝突，實則**測的是不同構件**：

| 典籍 | 測什麼 | 結論 |
|---|---|---|
| 《八宅明鏡》 | **爐具本體**（灶座）＋ 火門 | 灶座壓凶方、火門朝吉方 |
| 《陽宅三要》 | **廚房門** | 宜安生氣、天乙（天醫）、延年三吉方 |

《陽宅三要》原文：「**灶以廚房門為定之灶**……**是以灶之房門定灶，而非以灶門定灶也**」— https://fs.yi958.com/Article_11728.html

> **實作要求**：程式必須把廚房拆成 **`kitchen_door_position`（廚房門所在宮，宜吉方）** 與 **`stove_base_position`（爐具本體所在宮，宜凶方）** 兩個獨立欄位，外加 **`stove_mouth_facing`（火口朝向，宜吉方）**。用單一「廚房方位」欄位是錯的，且會讓兩派來源看起來互相矛盾。

### 2.7 命卦與宅卦不合的處理

#### 古籍立場：命卦優先

> 「**宅可改而命不可改，則當從命為吉。**」— 《八宅明鏡》 https://fs.qqqs.org/fssj/396.html
> 命宅不合「應以人的命卦吉向為準」— https://www.36fengshui.com/news/new4.asp

但同書亦強調兩者須兼顧：「**專論山向而不論命者大凶，論命不論山向者小凶**」——即只看宅不看命最糟，只看命不看宅次之，兩者俱全才是上策。

#### 各派處理方式

| 立場 | 主張 | 來源 |

| **命卦優先（古籍）** | 宅不可改而命不可改，從命為吉 | 《八宅明鏡》 |
| **分工論（英文主流）** | 兩者不衝突、各管一事：個人命卦管「人怎麼擺」（坐向、床頭、書桌朝向），宅卦管「哪些房間少用」 | https://www.fengshuiweb.co.uk/eight-mansions-feng-shui-2/ |

### 2.8 夫妻／家人命卦不同時的處理

#### 古籍層有明確主流：一家之主

| 主張 | 原文／說法 | 來源 |
|---|---|---|
| **家長年命（古籍主流）** | 「**凡論方向，只論家長年命**……**若家長沒後，以長子之命定之**……**若只有主母當家，以母為之**」 | 《八宅明鏡》 https://fs.qqqs.org/fssj/396.html |
| **以夫為主** | 「大抵**夫婦生命不同則當以夫為主**」 | 同上 |
| **經濟支柱（英文世界重詮）** | "The facing of the front door should **favour the breadwinner**." | https://www.fengshuiweb.co.uk/eight-mansions-feng-shui/ |
| **命卦優先於宅卦** | 「**宅可改而命不可改，則當從命為吉**」 | 同上／https://www.36fengshui.com/news/new4.asp |

**判定**：**古籍層有主流**（家長年命：夫 → 長子 → 主母當家則母），且命卦權重高於宅卦。但英文世界普遍改寫成「經濟支柱」，台港現代實務兩者並存，**現代實務層 [無法判定主流]**。

> **程式建議**：`primary_person` 由使用者選，**不要偷偷寫死性別**。古籍原文可作為「傳統作法」選項之一併陳。

#### 三種折衷做法（皆有出處）

**① 吉方分配法**
> 「不能只論男主人不論女主人。以男為主的，**把兩吉給男，一吉給女**；以女為主的反之。」
> 示範：門定男之生氣、房定延年、**灶安女主人的天醫方**。
> — https://wuyoushan.org/document.php?id=192

**② 救應法（古籍）**
> 「夫妻二命各東西者，**宜以夫命定灶口吉方，而外以床、房、廁各爻救妻可也**」
> — 主構件（門、灶口）依主命卦，次構件（床、房門、廁所）依副命卦。
> 古籍案例甚至用「另設小灶／風爐，口朝妻之吉方，使妻獨食」。
> — 《八宅明鏡》 https://fs.qqqs.org/fssj/396.html

**③ 分房法（古籍）——注意太極點**
> 各成員依自己命卦分配房間／床位，**太極點是父母的床，不是房屋中心**：
> 「如西命宜在**父母床身之西**安床吉，東則凶……故弟兄東命居東，西命居西則吉，**勿執哥東弟西之俗例**」。小孩房同理。
> — 同上

⚠️ 分房法的太極點設定（父母床）是程式很容易做錯的一點——不要預設用房屋幾何中心。

#### 明財位（象徵財位）

| 項目 | 內容 |

#### 明財位 vs 暗財位 vs 流年財位

| 類型 | 定義 | 取得方式 | 變動性 |
|---|---|---|---|
| 明財位 | 進門對角固定角落 | 目視即可 | 不變 |
| 暗財位 | 依宅之**坐向**推算的實質旺氣位 | 羅盤定坐向 → 排八宅或玄空飛星盤 → 找生氣位／當運旺星宮位 | 隨宅而異 |
| 流年財位 | 依當年**九宮飛星**飛臨位置 | 每年重排飛星盤 | 逐年變動 |

— https://kknews.cc/zh-tw/geomantic/62lx65l.html

> 本程式（八宅派）的「暗財位」應取**宅卦的生氣方**，而非玄空旺星。流年財位需九宮飛星模組，不在本期範圍。

### (c-2) 由爻變法生成遊星表（建議與上表互相驗證）

```js
// 八卦二進位：(初爻, 二爻, 三爻) 由下而上，陽=1 陰=0
const TRIGRAM_BITS = {
  乾: 0b111, 兌: 0b110, 離: 0b101, 震: 0b100,   // 位元由高到低 = (初, 二, 三)
  巽: 0b011, 坎: 0b010, 艮: 0b001, 坤: 0b000,
};

// XOR 遮罩 → 遊星（遮罩位元同樣是 (初, 二, 三)）
const MASK_TO_STAR = {
  0b000: "伏位", 0b001: "生氣", 0b010: "絕命", 0b011: "五鬼",
  0b100: "禍害", 0b101: "六煞", 0b110: "天醫", 0b111: "延年",
};

function starOf(houseGua, directionGua) {
  return MASK_TO_STAR[TRIGRAM_BITS[houseGua] ^ TRIGRAM_BITS[directionGua]];
}

// 驗證斷言：
// 1) starOf(a, b) === starOf(b, a)                       — 對稱性
// 2) starOf(a, a) === "伏位"                             — 自身必為伏位
// 3) 同組（東四/東四、西四/西四）必得四吉星，跨組必得四凶星
// 4) 每個卦的 8 個方位恰好各出現 8 個遊星一次
```

## 8. 給實作者的一頁摘要

1. **先做這三張表**：後天八卦常數（§5b）、八遊星 8×8（§5c）、二十四山（§5a）。全部有結構性斷言可寫成測試。
2. **八遊星表用推導函式生成**（§5c-2 的 XOR 查表），常數表只當回歸基準。本次調研正是靠對稱性斷言抓出某專業站的三處錯誤。
3. **命卦用統一通式**，不要用分世紀公式（2100 年起會錯）。注意 C 系語言的負數取模。
4. **立春必須用真實時刻**，不可寫死 2/4；缺出生時間且落在 2/3–2/5 時要提示補資料。
5. **磁偏角要顯式處理**：台灣約 −5°，已大於小空亡容許帶。預設磁北、同時顯示真北、可切換。
6. **凡 §6 列為 [有分歧] 的項目，一律不要硬編單一答案**——做成設定或並列顯示。最關鍵的三個：**起伏位五法**（D1，本程式採坐山，須明示）、**公寓取向**（D2，`facing_method` 必選參數）、**夫妻以誰為主**（D9，不要寫死性別）。
7. **廚房要拆三個欄位**：`kitchen_door_position`（宜吉方，《陽宅三要》）、`stove_base_position`（宜凶方，《八宅明鏡》）、`stove_mouth_facing`（宜吉方）。用單一「廚房方位」是錯的，且會讓兩派來源看起來互相矛盾。
8. **房間層級的預設是看「位」不看「向」**（古籍：「只論背座之方，不論向也」），唯一例外是灶口。
9. **分房法的太極點是父母的床，不是房屋幾何中心**——這是很容易做錯的一點。
10. **流派不可混用**：本程式是八宅派，人生領域用卦象本義，**不要輸出 BTB 黑派的九宮領域圖**；「廁所忌中宮」也不是八宅派的說法。
11. **神位與書桌別只給八宅結果**——現代台港實務不用八宅星定這兩項（神位走流年煞方、書桌論巒頭），只給八宅會與使用者看到的說法對不上。
12. **火口取「開關／點火處面」**（含電磁爐），不要用「瓦斯進氣口」（方向相反，台港查無）。
13. **文案一律中性**：「傳統認為…」，不做健康或財務承諾。
