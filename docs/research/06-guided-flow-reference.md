# 引導式問答的參考觀察（2026-09-07）

> 目的：釐清「為什麼我們的新手村會讓人出戲」，以及沉浸式引導在手機上實際怎麼做。
> 觀察對象：一個紫微斗數線上產品的免費問答段（登場頁 → 過場 → 對話 → 9 題問卷 → 寄送頁）。
> 只記手法與結構，不抄文案、不抄角色與場景；我們的版本是「師傅來看房」，見 `src/guide/`。

## 走一遍看到的結構

| 段落 | 內容 | 手法 |
|---|---|---|
| 登場頁 | 一張全版人物插畫、一行身分、一行社會證明、一顆 CTA | 沒有任何功能導覽，只有「這個人是誰」 |
| 過場 | 短動畫（可跳過、可開聲音） | 建立場景，讓後面的問題有「地點」 |
| 對話 | 打字機逐字出現、三個進度點、兩次二選一（選項是「使用者會說的話」） | 使用者從第一秒就在扮演角色 |
| 問卷 | 9 題，一題一畫面，題目壓在畫面下三分之一 | 拇指區；上面留白給氛圍 |
| 寄送頁 | 問要寄到哪，附一句隱私承諾 | 索取資料時仍維持口吻 |

## 讓人不出戲的關鍵（可沿用的原則）

1. **一題一畫面**，沒有表單感：沒有側欄、沒有卡片、沒有步驟名稱，只有細進度條與「n / 9」。
2. **題目用角色的口吻講**，短、像對話（「那天，是什麼時辰？」「男，還是女？」），不是欄位標籤。
3. **每題底下一行「為什麼要問」**，用角色的立場說（選錯了盤會歪、這題選錯哪段就白算）。這一行是整個流程最能建立信任的地方。
4. **題目上方一個小引子**（「問一句」「再問一句」「白天呢」）讓題與題之間像同一個人在接著問。
5. **每題都有台階**：不知道時辰可以先排殘盤、心事可以跳過。從不擋人。
6. **選項用人話**（有在猶豫的人、剛分開不久、接案自由業），兩欄格子，選中變色，再點一次或稍等才進下一題。
7. **轉場慢**：淡出 → 淡入約一秒，新題目由下往上浮，速度感是「對方在想」而不是「系統在切頁」。
8. **中途不給結果**：那個產品把揭曉留到付費之後。我們的產品反過來，要在中途就給價值（測試者要求：門口就先給財位），所以在「屋齡」之後插一段揭曉，每看完一間房也回一段。
9. **字體與色彩統一**：題目用襯線字、暗底、一個主色。UI 元件愈少，沉浸感愈強。

## 我們的版本與它的差異

- 場景是「師傅到你家門口看房」，不是上山問命；角色是嘟嘟師傅（Grok 生成的日式漫畫風插畫）。
- 主色沿用品牌的玉綠，暖光用燈籠色的暗金；不用紅金。
- 流程：門 → 當家的人 → 家人 → 屋齡 → **揭曉（宅卦、財位、文昌、命卦合不合）** → 主臥方位 → 床頭朝向 → **這間房的評語** → 還要看哪一間（迴圈）→ 總結（分數、最要緊三件事、今年五黃二黑）。
- 進度用固定七格的脊椎（門、當家、家人、屋齡、房間方位、朝向、還有嗎），房間迴圈停在最後一格。
- 每題保留台階：羅盤量、不知道屋齡、這間先跳過、不確定朝向。
