## 0.1 閱讀本文前必須知道的三件事

**1. 風水不是單一系統，是好幾套彼此衝突的系統。**
玄空飛星、八宅、三合、紫白九星⋯⋯各派的方位吉凶結論經常互相矛盾。程式若同時輸出多派結論，
必須讓使用者看得出「這是哪一派說的」，不能混成一鍋粥假裝是同一個真理。

**2. 本文只涵蓋「理氣」，不涵蓋「巒頭」。**
傳統認為「巒頭無理氣不準，理氣無巒頭不靈」——實體環境（路沖、水流、山形、鄰棟壓迫）
的權重不低於方位算式。純軟體做不到巒頭，這是本程式的**結構性限制**，應在 UI 明示。
形勢派規則見姊妹文件 `03-form-school-rules.md`。

**3. 這是文化／信仰體系，不是經驗科學。**
沒有對照實驗支持任何一條斷語。程式輸出宜用「傳統認為」「古籍記載」的語氣，
避免醫療、財務、法律面的確定性宣稱。

### 1.3 交運分界：立春（不是農曆正月初一）

**這是本次調研中最一致的一點，中／日／英文來源全數指向立春，未找到任何主張用農曆正月初一的玄空來源。**

| 來源 | 引述 |
|---|---|
| [滴天居士（新浪）](http://k.sina.com.cn/article_1472504524_57c4a2cc027013y5y.html) | 「年份的劃分按照干支曆是以**立春節氣**為歲首的，**並非公曆的 1 月 1 日或夏曆（農曆）的正月初一**」 |
| [搜狐：三元九運講解](https://www.sohu.com/a/824161838_122069232) | 「以**立春節氣為歲首**，而非公曆的 1 月 1 日或農曆的正月初一」 |
| [ELLE HK](https://www.elle.com.hk/astrology/dragon-year-2024-jiu-yun) | 「西曆 **2024 年 2 月 4 日立春後**，就是玄空風水所謂之下元九運新 20 年氣運的開始」 |
| Feng Shui Store（英） | "period 8 ends on the 4th of February 2024 and the same day, Period 9 begins" |

**九運自 2024-02-04（立春）起，不是 2024-02-10（農曆正月初一）。**

程式化：運界＝該年立春的節氣時刻（1900–2100 間立春落在 2/3～2/5，非固定 2/4）。

> ⚠️ **查無**：沒有來源說明立春「當日幾點」的處理慣例——是以交節的精確時分為界，
> 還是以立春當日 00:00 為界。程式須自行選定並標示（建議用精確交節時刻，與流年飛星一致）。

**少數說（不影響排盤）**：有主張依土木相會天象，九運已於 2020-12 開啟
（[蔣匡文](https://www.master-insight.com/article/37941)、Feng Shui Store）。
判定：曆法上一律 2024-02-04 起算，這是排盤程式該用的；「2020 已開始」是氣運體感論述。

**另一體系（不可混用）**：二元八運（玄空六法／談養吾派）只分上下二元、無五運，
各運年數不等（18/24/24/24/21/21/21/27）。
[星林學苑](https://www.108s.tw/article/info/290) 明確警告「這與玄空六法的二元八運是不同的，千萬別搞混」。
主流仍是三元九運。

### 1.4 各運的星曜狀態（旺／生／進／退／衰／死／煞）

查到三種粒度並存，**程式必須先選一種**：三分法（當令／未來／退運）、五分法（旺生退死煞）、
七分法（旺生進退衰死煞）。**七分法最細，且能推導出前兩者**，建議採用。

**七分法公式（本文推導，已用來源全表反覆驗證）**：令 `d = (星數 − 運數) mod 9`

| d | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| 狀態 | **旺** | 生 | 進 | 煞 | 煞 | 煞 | 死 | 衰 | 退 |

**九運（2024–2043）逐星狀態**：

| 星 | 九紫 | 一白 | 二黑 | 三碧 | 四綠 | 五黃 | 六白 | 七赤 | 八白 |
|---|---|---|---|---|---|---|---|---|---|
| d | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| **狀態** | **旺（當運）** | **生氣** | **進氣** | 煞氣 | 煞氣 | 煞氣 | 死氣 | 衰氣 | **退氣** |

原文：「9が『旺気』で令星となります。そして 1 は『生気』続いて 2 は『進気』となるのです。
しかしこれまで令星であった 8 は『退気』となって力が弱くなります。」
— [現代風水研究会](https://www.gendaifusui.com/genku/)（該站列出九運全表，是本次找到唯一一張九運齊全的狀態表）

**驗證**：用上述公式重算該來源九列全表，**8 列完全吻合**；第 7 運那列原文寫「2・1・9 煞氣」
與第 6 運那列重複，公式給出 1・2・3 — **判定為來源抄錄錯誤**（這是本文發現的第三處公開資料錯誤）。

**五分法（中文維基百科）**：`d`→ 0 旺、1–2 生、3–4 死、5–7 煞、8 退。
九運逐星：九紫旺、一白生、二黑生、三碧死、四綠死、五黃煞、六白煞、七赤煞、八白退。
定義句：「得令而『生』為吉，當運而『旺』為大吉，初失令而『退』為不凶不吉，
其後為『煞』漸凶，至『死』為大凶，而後復得令而『生』。」
— [中文維基：九宮飛星圖](https://zh.wikipedia.org/zh-tw/九宮飛星圖)

**三分法**：得令三吉星＝ n, n+1, n+2。維基原文：
「2024 年到 2043 年九運時；**九紫、一白、二黑是得令的吉星**。」

> ⚠️ **分歧（無共識，程式須讓使用者選派別）**：
> - **死氣／煞氣的邊界**：維基（煞＝d5,6,7、死＝d3,4）vs 日本七分法（死＝d6、煞＝d3,4,5）— **完全相反**。
> - **煞氣是否為時間分類**：Feng Shui Store 主張煞氣與元運正交，可在任何時候出現。
> - **退氣取幾顆**：中文圈主流一顆（n−1）；Feng Shui Store 取兩顆（n−1、n−2）。
> - **生氣取幾顆**：兩顆為主流（六個獨立來源）；有來源細分「一＝近生氣、二＝遠生氣」。

**三般卦的覆寫層**：父母三般卦（147/258/369）成局時「能通三運為氣，一運為旺，其餘兩運亦旺」，
可使上山下水、反吟伏吟不致為凶。**這是疊在標準旺衰表之上的覆寫，成局時把同組另兩運的星一併升格。**
— [太極智典](https://www.taijizhidian.com/yijingzixu/25642.html)、[加拿大國際風水命理研究中心](http://www.cafengshuinet.com/m/show_detail.php?id=3012)

> ⚠️ **術語陷阱（程式必須避開）**：「零水／正水」這組名稱**與直覺相反**，且與「零神水」不是同一個詞：
> 「**當運的旺星位有水，叫零水**…零水是凶水。當運旺星的對宮位有水，叫正水…**正水是財水**。」

> 而 36fengshui 用「零神水」指「零神方之水」（吉）。同一件事有兩套相反的標籤。

### 2.5 山盤與向盤（含「二次轉換」規則）

這是全套規則最繞的一段。完整表述：

1. 取**坐山所在宮**的運星 → 此數入中，成為**山盤**中宮星。
2. 取**向首所在宮**的運星 → 此數入中，成為**向盤**中宮星。
3. 決定順逆（關鍵，需要「二次轉換」）：
   - 設入中的星數為 `S`，坐山（或向）所屬元龍為 `Y`（地/天/人）。
   - `S` 這個數字**對應到後天八卦的同號宮**（例如 S=4 → 巽宮，S=1 → 坎宮）。
   - 在**那個宮**裡，找出**與 `Y` 同元龍**的那一座山。
   - 讀那座山的陰陽：**陽則順飛，陰則逆飛**。

原文引述：「找出山/向屬於哪個元龍（地/天/人元龍）→ 該運星數對應後天八卦的卦位 → 查該卦位中對應元龍的陰陽屬性 →『屬陽順飛，屬陰逆飛』」
— [星林學苑：玄空飛星盤，排列星盤的方式](https://www.108s.tw/article/info/292)

> **注意**：判斷陰陽用的是「入中星數所落之宮的同元龍山」，**不是坐山本身的陰陽**。
> 唯一用坐山本身陰陽的情況是 5 入中（見 2.6）。這一點極易寫錯。

**實例走一次（九運子山午向的向盤）**：
向首是午，在離宮；離宮運星 = 4 → 4 入中。
午屬**天元龍** → 看 4 號宮（巽宮）的天元龍 = **巽** → 巽為**陽** → **順飛**。

### 2.6 五入中（無正卦）的處理

5 沒有對應的後天卦，無法做 2.5 的二次轉換。主流規則：**改用坐山／向首本身的陰陽**。

- 山盤 5 入中 → 用**坐山**那一座山的陰陽
- 向盤 5 入中 → 用**向首**那一座山的陰陽

來源（三處一致）：
- 「五黃入中，因五黃本身無山向可言，五入中的順飛逆飛由五所落宮位的陰陽性質決定」 — [搜狐：星盤起法圖解](https://www.sohu.com/a/273590242_435999)
- 「五入中之後對應的中宮無替可尋，仍以建築的元龍性質定陰陽，然後確定順排逆排」 — [加拿大國際風水命理研究中心](http://www.cafengshuinet.com/m/show_detail.php?id=957)
- 「もし中宮に5という数字が入った場合は…座山なら座山、座向なら座向、二十四山の陰陽によって順飛と逆飛を決めます」 — [現代風水研究会：玄空風水秘訣の要約](https://www.gendaifusui.com/genku/)

UI 明確標示：


### 2.8 格局判定規則

令 `P` = 元運數、`SP` = 坐山所在宮、`FP` = 向首所在宮、
`M[]` = 山盤、`F[]` = 向盤、`R[]` = 運盤、`L[k] = k`（元旦盤，因宮位 ID 即洛書數）。

| 格局 | 判定條件 | 吉凶 |
|---|---|---|
| **旺山旺向**（到山到向） | `M[SP]==P and F[FP]==P` | 大吉，丁財兩旺 |
| **上山下水** | `M[FP]==P and F[SP]==P` | 大凶，損丁破財 |
| **雙星到向**（雙星會向） | `M[FP]==P and F[FP]==P` | 財運大吉、丁運小吉 |
| **雙星到坐**（雙星會坐） | `M[SP]==P and F[SP]==P` | 健康人丁大吉、財運小吉 |
| **全盤合十** | `all(M[k]+R[k]==10)` 或 `all(F[k]+R[k]==10)` | 吉，山星合十旺丁、向星合十旺財 |
| **全盤伏吟** | `all(M[k]==R[k])`（與運盤同）或 `all(M[k]==L[k])`（與元旦盤同） | 凶，主呆滯壓抑 |
| **全盤反吟** | `all(M[k]+L[k]==10)`（與元旦盤合十） | 凶，主動盪反覆 |
| **局部伏吟** | 單宮 `M[k]==R[k]` 或 `F[k]==R[k]` | 該宮小凶 |
| **父母三般卦** | 每宮 `{R[k],M[k],F[k]}` 同屬 `{1,4,7}`／`{2,5,8}`／`{3,6,9}` 之一組 | 大吉，通三元不敗 |
| **連珠三般卦** | 每宮 `{R[k],M[k],F[k]}` 為連續三數（含 8-9-1、9-1-2 循環） | 吉 |

格局吉凶來源：[現代風水研究会](https://www.gendaifusui.com/genku/)「旺山旺向：健康財運共吉／雙星到座：健康運大吉，財運小吉／雙星到向：財運大吉，健康運小吉／上山下水：共凶／合十：運星與山/水星合計為 10」

#### 反吟／伏吟的精確定義（已找到直接定義來源並實測驗證）

原文：
> 「全盤的山星或向星與洛書元旦盤的飛星『**順序相同**』時，稱作**伏吟**」
> 「山向二星遇到五黃入中宮順飛，其飛佈之星數字必然與元旦盤相同」
> 「全盤的山星或向星與洛書元旦盤的飛星『**順序相反**』時，稱作**反吟**」，
> 簡單判定方式為「山星或向星與洛書元旦盤的飛星數字**加起來為 10**」
> — [星林學苑：伏吟反吟](https://www.108s.tw/article/info/300)

因宮位 ID 即洛書數，程式寫法極簡：

```python
伏吟 = all(P[k] == k for k in 1..9)      # 與元旦盤相同
反吟 = all(P[k] + k == 10 for k in 1..9) # 與元旦盤合十
```

**另有一種「與運盤相同」的局部伏吟**：九運子山午向的震宮山星 7 ＝ 運星 7，
來源稱「震宮山星與運盤同(72七)，**犯伏吟**」— [九運子山午向運用](https://vocus.cc/article/648c769afd89780001c93f95)。
所以伏吟有兩個判準（對元旦盤、對運盤），程式應分別標示，不要混為一談。

**實測比對**：該來源列出八運全盤反吟／伏吟的六個坐向，引擎掃描結果 **5/6 完全吻合**：

| 坐向 | 來源宣稱 | 引擎判定 | |
|---|---|---|---|
| 丑山未向 | 向星反吟 | 向星反吟 | ✅ |
| 艮山坤向 | 向星伏吟 | 向星伏吟 | ✅ |
| 寅山申向 | 向星伏吟 | 向星伏吟 | ✅ |
| 未山丑向 | 山星反吟 | 山星反吟 | ✅ |
| 申山寅向 | 山星伏吟 | 山星伏吟 | ✅ |
| 坤山艮向 | 山星**反**吟 | 山星**伏**吟 | ⚠️ 來源自相矛盾 |

**坤山艮向的差異是來源錯誤**，理由有三：
1. 該來源自己把坤山艮向列在「**全盤伏吟**坐向」的標題底下，標籤卻寫成「反吟」，前後矛盾。
2. 引擎算出的坤山艮向山盤是 `[1,2,3,4,5,6,7,8,9]` — **就是元旦盤本身**，依該來源自己的定義即為伏吟。
3. **鏡像性質**：坐向對調時山盤與向盤必然互換（引擎全掃描 9 運 × 24 山 = **216 組全部成立**）。
   既然艮山坤向是向星伏吟，其鏡像坤山艮向就必為山星伏吟。

> 這是本次調研發現的**第二處公開資料錯誤**。風水網站的盤面與斷語抄錯率不低，
> 程式若要引用外部資料建表，務必用不變量（排列性、鏡像性、合十性）先過濾一遍。

#### 發現一處公開資料錯誤（可用來說明本引擎的驗證強度）

[星林學苑 辰山戌向 下元九運](https://www.108s.tw/article/info/364) 的震宮山星寫作 **8**，
本引擎算出 **1**。這不是見解不同，而是**該來源必定有誤**，證明如下：

> 飛星盤的每一盤（運／山／向）都是 **1–9 的排列**，每個數字恰好出現一次
> —— 這是「入中順飛或逆飛」的直接數學後果。
> 該來源的山盤數字集合為 `{2,3,4,5,6,7,8,8,9}`：**8 出現兩次（中宮與震宮）、1 完全缺席**，
> 違反排列不變量。引擎的 `{1,2,3,4,5,6,7,8,9}` 才是合法盤。
> 其餘 8 宮 24 個數字與該來源完全一致，可見只是震宮一格誤植（且誤植值恰為中宮值）。

**對程式的意義**：把「每盤必為 1–9 的排列」寫成 assertion，可以擋掉幾乎所有排盤 bug。
本引擎全掃描 9 運 × 24 山 × 3 盤 = **648 張盤，零違反**。這條不變量是最便宜、最有效的自我檢查。

**追加結構性驗證（不需外部來源，用理論自洽性檢查引擎）**：

因為天元龍與人元龍在每一宮的陰陽必定相同（天元 乾坤艮巽陽／子午卯酉陰；
人元 寅申巳亥陽／癸丁乙辛陰 — 逐宮比對，八宮全部同號），可推論：

> **同宮的天元山與人元山，下卦盤必定完全相同。**（子＝癸、艮＝寅、卯＝乙、巽＝巳、
> 午＝丁、坤＝申、酉＝辛、乾＝亥）

程式掃描 9 運 × 8 對 = 72 組，**全部成立**；而天元 vs 地元則 72/72 全部不同。
這正是**替卦存在的理由** — 下卦法無法區分天元與人元，必須靠替卦才能分開。
引擎能自動重現這個理論性質，是它規則正確的獨立佐證。

> **對 UI 的意義**：使用者輸入「坐子」與「坐癸」會得到一模一樣的盤。這不是 bug，
> 應在介面說明，否則使用者會以為系統沒吃到輸入。

### 2.12 兩條可大幅簡化程式的定理（本文推導 + 全面驗證）

這兩條是本次調研的意外收穫，能讓格局判定不必逐宮掃描：

**定理一：飛行方向直接決定旺星落點**
> **山盤逆飛 ⇔ 山之旺星到坐；山盤順飛 ⇔ 山之旺星到向。**
> **向盤逆飛 ⇔ 向之旺星到向；向盤順飛 ⇔ 向之旺星到坐。**

證明：`運盤[坐宮] = n + d[坐宮]`，山盤逆飛時 `山盤[坐宮] = (n+d) − d = n`。
引擎驗算 **432 組零違反**。

推論（**僅適用下卦，替卦盤失效**）：

| 格局 | 等價捷徑 |
|---|---|
| 旺山旺向 | 山盤逆飛 且 向盤逆飛（入中山向二星俱陰） |
| 上山下水 | 山盤順飛 且 向盤順飛（俱陽） |
| 雙星到向 | 山盤順飛 且 向盤逆飛 |
| 雙星到坐 | 山盤逆飛 且 向盤順飛 |

**定理二：全盤伏吟／反吟的充要條件**
> **入中星為 5 且順飛 ⇔ 該盤全盤伏吟（＝元旦盤）**
> **入中星為 5 且逆飛 ⇔ 該盤全盤反吟（與元旦盤逐宮合十）**

引擎驗算 **216 組零違反**。
進一步：`運盤[P]==5` 的宮位唯一（其 d = (5−n) mod 9），
所以「**坐山或向首恰好落在該宮**」就是全盤伏吟／反吟的充要條件，順逆再決定是伏是反。

> **注意**：程式仍應用逐宮的標準判定（可讀性高、且替卦盤下依然正確），
> 這兩條定理的價值在於**當單元測試的交叉驗證**——兩條路徑算出不同答案就是有 bug。

### 3.4 覆蓋度與「81 還是 80」— 本文以程式實證解答

**覆蓋度**：81/81 組皆有至少一個中文來源的斷語（來源 B）。
其中 79 組有兩個以上獨立來源可交叉比對；**1-1 只有單一來源**（英文來源 A 完全缺此條），
**9-3 在來源 A 被與 3-9 合併**成一條（且原文標題誤植為「3-9 & 3-9」）。

| 來源 | 覆蓋 | 缺漏 |
|---|---|---|
| B（中文） | **81/81**（分山向順序） | 無 |
| A（英文） | 79/81 有獨立條目 | 1-1 完全缺；3-9 與 9-3 合併 |
| C（中文） | 45/45 無序組合 | 不區分 1-4 與 4-1 |
| J（英文 fengshuitime） | 81/81 但**只有五行陰陽對照，無吉凶斷語** | 無斷語 |
| I（Imperial Harvest） | 表格為**圖片**，文字版查無 | 內容不可取 |

**「其實只有 80 組」的說法 — 本文已用程式證實，並找出是哪一組。**

[Feng Shui Mechanics](https://fengshuimechanics.com/2013/04/03/81-combination-in-flying-star/) 主張：
> "actually in reality there is only 80 possible combinations since 1 set is missing.
> Which is the missing combination? You can check all the 9 period chart and 1 combination is missing…
> It exists because in WuChang we can have this combination."

該文**沒有說是哪一組**。本文用已驗證的排盤引擎窮舉
**9 運 × 24 山 × 9 宮 = 1944 格**，結果：

> **出現 80 組，唯一從未出現的是 `5-5`。**
> 進一步檢查：全部 216 張盤中，**山盤的 5 與向盤的 5 從未落在同一宮**（0/216）。

這證實了該來源的主張，並補上它沒給的答案。附帶發現：

| 組合 | 在下卦盤中的出現次數 | 備註 |
|---|---|---|
| 5-5 | **0** | 下卦永不出現；僅替卦（無常派）可能產生 |
| 1-9 / 9-1 | 各 3 次 | **只出現在五運的中宮**，且僅限壬子癸／丙午丁軸 |
| 2-2、3-3、4-4、6-6、7-7、8-8 | 各 12 次 | — |

**對程式的意義**：81 組合表仍應完整建 81 筆（替卦與教學用途需要 5-5），
但可在 UI 標示「5-5 在下卦盤中不會出現」。若排盤結果出現 5-5，**那是 bug**——
這是另一條免費的自我檢查不變量。

### 3.5 當運／失運的吉凶反轉規則

### 4.4 化解的根本原則（有古籍依據，可寫成程式規則）

**規則一：化煞優於制煞（用「洩」不用「剋」）**

> 《紫白訣》：「第以煞旺求生旺…**然而制煞不如化煞**、或鐘樓鼓角、局山生旺施工。」
> — [《紫白訣》全文](http://www.wisesociety.com.hk/zi-bai-jue/)
>
> 《飛星賦》：「須知七剛三毅，**剛毅者制則生殃**。」註解：「即係**只可以化殺，唔可以制殺**…
> 化解之法只可用**洩金之氣**而唔可以用鬥殺之法，可用**動水洩金生木**之法，例如擺一個魚缸，放魚三條」
> — [《飛星賦》原文＋註解](http://www.wisesociety.com.hk/fei-sing-fu/)

**由此推導出的五行洩化表（可直接寫成程式）**：

| 凶星 | 五行 | 化解（洩） | 忌（會助長） |
|---|---|---|---|
| 二黑 2 | 土 | **金**（金洩土） | 火（火生土）、紅色 |
| 五黃 5 | 土 | **金**（金洩土） | 火、紅色、**動土** |
| 三碧 3 | 木 | **火**（火洩木） | 水（水生木） |
| 七赤 7 | 金 | **水**（水洩金） | 土（土生金） |
| 九紫 9（失運） | 火 | **土**（土洩火） | 木（木生火） |

**規則二：缺角補五行、凸出洩五行**
> 「簡單的來說，**缺角要補足五行，凸出要洩掉五行**，可搭配家具的材質、形狀來達到。」
> — [星林學苑](https://www.108s.tw/article/info/291)

**規則三：一貴當權，群凶懾服（先催吉、後化凶）**
> 「不要花時間在不重要的飛星上…**首先要處理吉星**，當吉星被催至最旺的時候，其他飛星便顯得不重要」
> — [斷事原則](https://blog.sina.com.cn/s/blog_af85ff5f0102yrmr.html)

**規則四：飛星須有巒頭／氣口配合才應驗（對本程式極重要）**
> 「所有飛星**只有在一種情況下才會應驗**，就是那個位置出現了一個**與飛星有關的巒頭**，才會使飛星應驗…
> **［氣口司一宅之樞］**…打開窗是氣口，抽氣扇、甚至抽濕機都是氣口。」
> — 同上

**這條規則的意義**：純理氣程式**無法判斷該宮是否有氣口**。
建議程式讓使用者勾選「此方位有無門／窗／常開的出入口」，作為斷語強度的權重。
沒有氣口的凶星宮，凶性大幅降低。

## 5. 流年、流月飛星

> 本節公式經兩條獨立路徑各自實作驗算，結果完全一致；並對照 2023–2027 五年的公開九宮圖逐宮比對。
> **可信度：高**（這是全文最硬的部分——純算術，沒有詮釋空間）。

### 5.1 流年飛星入中公式

```python
def year_star(solar_year: int) -> int:
    """流年紫白入中星 (1..9)。solar_year 為節氣年（立春後才換）。"""
    r = (11 - (solar_year % 9)) % 9
    return 9 if r == 0 else r
```

古法寫法（心算用，代數上等價）：西元年四位數字相加 → 用 11 減之 → 若和大於 11 先折疊、結果為 0 視為 9。
例：2026 → 2+0+2+6 = 10 → 10 mod 9 = 1 → 11−1 = 10 → 10−9 = **1（一白入中）**。
— [CSDN：紫白飛星法](https://blog.csdn.net/weixin_34334554/article/details/112880704)、[新浪 blog](https://blog.sina.com.cn/s/blog_af85ff5f0102yhtk.html)

因為 `digit_sum(y) ≡ y (mod 9)`，程式直接用 `y % 9` 即可，不必真的拆數字。

### 5.2 三元不影響年星公式（重要，可省一堆程式碼）

文獻常說「上元甲子一白入中、中元甲子四綠入中、下元甲子七赤入中」，容易讓人以為公式要分三元。**實測三個甲子年，同一條公式全中**：

| 元 | 甲子年 | 公式結果 | 文獻記載 | 一致 |
|---|---|---|---|---|
| 上元 | 1864 | 一白 | 上元甲子一白入中 | ✅ |
| 中元 | 1924 | 四綠 | 中元甲子四綠入中 | ✅ |
| 下元 | 1984 | 七赤 | 下元甲子七赤入中 | ✅ |

數學原因：三元共 180 年，`180 mod 9 = 0`，三元相位完全重合，`y % 9` 已把三元資訊吃掉。
→ **程式不需要分三元判斷。**（注意：這與「三元九運影響玄空宅盤旺衰」是兩回事。）

> 「順飛」講的是**九宮內部排布**。兩者不衝突，是兩個不同層次。

**方向：「逐月星逆、宮位順」** — 入中星逐月遞減 1（8→7→6→5→4→3→2→1→9→8→7→6），
但每個月盤內部仍是洛書順飛。

**另一條等價閉式公式**（不需查年支表，適合當單元測試的交叉驗證）：

```python
def month_star_closed(year_star, month_index):
    """month_index: 寅月=1 … 丑月=12"""
    r = (3 * year_star - 3 - month_index) % 9
    return 9 if r == 0 else r
```

已驗證與查表法在 2024–2029 六年完全等價。

**月的分界＝節氣的「節」，不是農曆月**。12 個換月節：立春、驚蟄、清明、立夏、芒種、
小暑、立秋、白露、寒露、立冬、大雪、小寒。（雨水、春分等 12 個「中氣」不換月。）
— CSDN：「以節氣為分界，不按農曆月份計算」。**分歧**：cnddy.com 主張用農曆月，見 §10。

## 7. 玄空與八宅並用

> **可信度：C。** 這一節沒有統一答案——業界存在三種明確且互相衝突的立場。
> 本節的價值不是給出「正確做法」，而是讓程式知道**自己在替使用者做哪一個門派選擇**。

### 7.1 兩派的理論衝突點

| 面向 | 八宅（大遊年／東西四命） | 玄空飛星 |
|---|---|---|
| 吉凶來源 | 宅卦 × 人命卦的**固定**生剋（八遊星） | 元運 × 坐向 × 飛星組合的**時空變動** |
| 時間變數 | **無**。宅一經定向，吉凶方位永遠不變 | 有。三元九運、流年流月流日皆可推 |
| 個人化 | **有**（東四命／西四命，以出生年定命卦） | 原則上**無**（同棟同坐向者盤相同） |
| 判斷粒度 | 八方位吉凶標籤 | 每宮山／向／運三星組合＋衰旺 |

**衝突是結構性的，不是細節差異**：同一方位可以在玄空是當運旺星（大吉），
在八宅卻落在絕命／五鬼（大凶），反之亦然。

### 7.2 業界三種立場（不存在單一共識）

**立場 A — 玄空為主、八宅為輔（並用派，實務最常見）**

[中觀國學《三合、玄空、八宅、奇門風水的運用比對》](https://www.yixiansheng.com/article/4630.html)
給出的分工最具操作性：

| 物業型態 | 主方法 | 輔方法 |
|---|---|---|
| 小面積住宅 | **八宅派** | 宮星刑剋生合 |
| 大面積、自成一局（工廠／獨棟） | **玄空飛星** | 周邊形勢 |
| 大廈住宅單位 | **以大廈為立極點用玄空看外部形勢** | **室內用八宅法佈局** |

該文對兩派短板的評價值得直接引用：
> 玄空的短板：小面積住宅「**高低難斷、虛實不明，故準確性也當受質疑**」；
> 室內「桌椅、床、沙發等錯落相間，山、水混雜，何為大小高低難以量化」。
> 八宅的短板：「**對大面積獨立建築內部評判深度不足**」。
> 衝突取捨：「**當大局不利時，便要捨大局，以求小局吉利，則其自吉矣**」。

天星風水張聿麒的折衷立場也屬此類——嚴厲批評命卦但保留遊星：
> 「八宅派的風水理論過於簡單粗略。特別是東四命配東四宅、西四命配西四宅的觀點更是粗陋不堪…
> **但以遊星論吉凶，在放門路或在室內佈局與玄空飛星配合起來可有參考價值。**」
> — [vocus](https://vocus.cc/article/623d59f8fd897800017405ee)

**立場 B — 純玄空、明確拒斥八宅（純粹主義）**

> 「柏老師的風水鑑宅，係以正統的『玄空飛星』布局，**不雜『八宅派』或其他雜派見解**」；
> 批評八宅「僅以年命將人分類，而且宅位一經確定，吉凶方位永遠固定不變，
> 完全不符合宇宙地氣運轉之法則」；引清朝大師語
> 「**坐山定宅，宅既不真，東西四宮，宮亦全謬**」，斷言八宅「就是『偽學』，純屬欺騙」。
> — [powerluck.tw](https://www.powerluck.tw/knowledge/74-363-1)

實務轉派經驗：作者原用八宅，「發現**它並不靈驗，效果並不好**…入宅推斷風水吉凶時，
答案常常被當事人否定」，最終改用玄空。— [ijfate.com](https://ijfate.com/p003/)

**立場 C — 以八宅為主（少數但確實存在）**

沈朝合老師公開自陳「我判斷風水是運用什麼派別？我的回答是**八宅派**」。
— [Facebook](https://www.facebook.com/Huludun/posts/1109219835771740/)

香港 hokming.com 的中性描述：「現時風水師**多採用『玄空飛星派』**」，兩派「各有優劣」。

### 7.3 衝突時的取捨 — 可寫進程式的優先序

業界**沒有統一裁決規則**，但有三條被反覆表述的原則：

1. **巒頭壓過一切理氣**：形勢已凶，兩派誰吉都不算數。
2. **大局讓小局**：「當大局不利時，便要捨大局，以求小局吉利」——
   外部大環境（玄空管的）不利時，退而求室內佈局（八宅管的）合宜。
3. **尺度分工**：外部／全宅／時間 → 玄空；室內／點位（門、床、灶、桌）／個人 → 八宅遊星。

### 7.6 巒頭與理氣的權重

| 表述 | 出處 |
|---|---|
| 「巒頭為主、為體，理氣為變、為用。**巒頭決定了風水的吉凶，理氣決定了風水的吉凶程度**」 | [中觀國學](https://www.yixiansheng.com/article/4630.html) |
| 「不管用何種方法，**首先必須形勢（巒頭）要符合風水理論，否則已凶！在此基礎上，方可談理氣**」 | 同上 |
| 「**不知巒頭者，不可與言理氣；不知理氣者，不可與言巒頭**」（古云） | [張聿麒轉引](https://vocus.cc/article/623d59f8fd897800017405ee) |
| 「**巒頭無假，理氣無真**」——「巒頭不好，那怕甚麼珠寶線、大金龍都沒有作用」 | [林國誠](https://www.stheadline.com/opinion/3372570/) |
| 「風水必須**理氣加上巒頭相互配合，兩者缺一不可**」 | [星林學苑](https://www.108s.tw/article/info/295) |
| 風水在人生總分中「佔的比例也只有約 **30%**，僅能錦上添花，或雪中送炭，極難能起死回生」 | 張聿麒 |

> ⚠️ **「巒頭無理氣不準，理氣無巒頭不靈」這句原句本身：出處查無。**
> 只找到同義的「巒頭無假，理氣無真」與「不知巒頭者不可與言理氣」有明確載體。
>
> ⚠️ **「三分理氣七分巒頭」等具體比例：查無一手來源。**

**是否有共識？優先序有，權重比例沒有。**
幾乎所有來源（含純玄空派、並用派、形學派）都同意「先巒頭、後理氣」「巒頭為體、理氣為用」。
分歧在於：形學派認為巒頭不好就無解；理氣派（林國誠）反駁「若僅推說巒頭不佳而無解決方案，
則**學藝未精**」，主張受限空間仍可靠「門路位置的氣口、房內的高低」調整。

### 7.7 純理氣程式必須標示的限制（本節對本專案最重要）

**硬事實三條**（每條都有出處，不是本文的謙辭）：

1. **玄空判詞本身就內建巒頭前提。**
   旺山旺向的**完整**條件是「山盤旺星在房屋後面有一棟同等高度的房屋作為靠山，
   向盤旺星在大門正前方有大馬路（至少四線道）或社區有噴水池、游泳池、景觀河」——
   **沒有這些形勢，「旺山旺向」四個字不成立。**
2. **收山出煞、城門訣、七星打劫、囚不住，全部以巒頭（見山／見水／開口通氣／水光）為生效條件。**
   純理氣只能輸出「候選」，不能輸出「成立」。
3. 因此程式對每個格局應輸出**兩段式**：
   `理氣判定：成立` ＋ `巒頭條件：未驗證（需現場確認 ___）`，而不是直接給吉凶結論。

**建議讓使用者自行輸入的最小巒頭要素清單**（每項都影響某個判定）：

| 要素 | 影響哪個判定 |
|---|---|
| 坐方是否見山／同高建物 | 旺山旺向、雙星到坐、收山出煞 |
| 向方是否見水／大馬路／水池 | 旺山旺向、雙星到向、收山出煞 |
| 大門在哪一宮 | 門星、納氣、八宅伏位 |
| 城門宮是否為陽台／窗／便門（非牆） | 城門訣是否生效 |
| 城門宮外是否有水口／十字路口／天橋 | 城門訣是否生效 |
| 向盤五黃宮是否有門／路／見水光 | 入囚能否「囚不住」 |
| 打劫三宮是否通氣、外部是否空缺 | 七星打劫是否生效 |
| 路沖／直衝門的道路 | 形法派凶煞 |
| 床、灶、書桌、神位位置 | 八宅點位配置 |
| 是否有臨近高樓逼壓向首 | 「水星上山」，旺向星失效 |
| **該宮是否有氣口（門／窗／常開出入口）** | **所有飛星斷語的強度**（見 §4.4 規則四） |

> 最後一項最容易被忽略但最關鍵：
> 「**所有飛星只有在一種情況下才會應驗**，就是那個位置出現了一個與飛星有關的巒頭…
> ［氣口司一宅之樞］」。**沒有氣口的凶星宮，凶性大幅降低。**

### 8.3 排盤演算法（pseudo code）

```python
FLIGHT_ORDER = [5, 6, 7, 8, 9, 1, 2, 3, 4]

def fly(center_star, forward):
    """從中宮起沿洛書路徑佈星。forward=True 順飛(+1)，False 逆飛(-1)。"""
    plate, s = {}, center_star
    for palace in FLIGHT_ORDER:
        plate[palace] = s
        s = (s + (1 if forward else -1) - 1) % 9 + 1   # 1..9 循環
    return plate


def degrees_to_mountain(deg):
    """羅盤度數 → 24 山。回傳 (山, 距該山中心的偏移度數)。"""
    idx = int(((deg - 337.5) % 360) // 15)     # 壬山起算
    m = MOUNTAINS[idx]
    center = (m.startDeg + 7.5) % 360
    offset = ((deg - center + 180) % 360) - 180
    return m, offset


def yin_yang_for(star, yuan, fallback_mountain):
    """二次轉換：star 落在同號宮，取該宮中同元龍的山，讀其陰陽。
       star==5 無正卦 → 改用坐山/向首本身的陰陽。"""
    if star == 5:
        return fallback_mountain.yy          # 五入中特例
    for m in MOUNTAINS:
        if m.palace == star and m.yuan == yuan:
            return m.yy
    raise AssertionError("unreachable")


def build_chart(period, sitting_mountain):
    facing = MOUNTAINS[(index_of(sitting_mountain) + 12) % 24]

    # 1. 運盤：元運數入中，一律順飛
    period_plate = fly(period, forward=True)

    # 2. 取坐山宮 / 向首宮的運星入中
    mtn_center = period_plate[sitting_mountain.palace]
    fac_center = period_plate[facing.palace]

    # 3. 各自定順逆
    mtn_fw = yin_yang_for(mtn_center, sitting_mountain.yuan, sitting_mountain) > 0
    fac_fw = yin_yang_for(fac_center, facing.yuan,           facing)           > 0

    return {
        "period": period_plate,
        "mountain": fly(mtn_center, mtn_fw),   # 山盤（管人丁、健康）
        "facing":   fly(fac_center, fac_fw),   # 向盤（管財運）
        "sitPalace": sitting_mountain.palace,
        "facePalace": facing.palace,
    }
```

### 8.4 格局判定（pseudo code）

```python
def classify(chart, period):
    M, F, R = chart.mountain, chart.facing, chart.period
    SP, FP = chart.sitPalace, chart.facePalace
    L = {k: k for k in range(1, 10)}          # 元旦盤：宮位 ID 即洛書數
    tags = []

    # --- 四大基本格局（互斥） ---
    if   M[SP] == period and F[FP] == period: tags.append("旺山旺向")
    elif M[FP] == period and F[SP] == period: tags.append("上山下水")
    elif M[FP] == period and F[FP] == period: tags.append("雙星到向")
    elif M[SP] == period and F[SP] == period: tags.append("雙星到坐")

    # --- 合十 ---
    if all(M[k] + R[k] == 10 for k in range(1,10)): tags.append("全盤山星合十")
    if all(F[k] + R[k] == 10 for k in range(1,10)): tags.append("全盤向星合十")

    # --- 反吟 / 伏吟 ---
    for label, P in (("山盤", M), ("向盤", F)):
        if all(P[k] == R[k] for k in range(1,10)): tags.append(f"{label}全盤伏吟(與運盤同)")
        if all(P[k] == L[k] for k in range(1,10)): tags.append(f"{label}全盤伏吟(與元旦盤同)")
        if all(P[k] + L[k] == 10 for k in range(1,10)): tags.append(f"{label}全盤反吟")

    # --- 三般卦 ---
    PARENT = [{1,4,7}, {2,5,8}, {3,6,9}]
    if all(any({R[k],M[k],F[k]} <= g for g in PARENT) for k in range(1,10)):
        tags.append("父母三般卦")
    if all(is_consecutive({R[k],M[k],F[k]}) for k in range(1,10)):
        tags.append("連珠三般卦")

    # --- 局部伏吟（逐宮） ---
    local = [k for k in range(1,10) if M[k]==R[k] or F[k]==R[k]]
    return tags, local


def is_consecutive(s):
    """三數連續，含 8-9-1、9-1-2 循環"""
    if len(s) != 3: return False
    v = sorted(s)
    return (v[1]-v[0] == 1 and v[2]-v[1] == 1) or s in ({8,9,1}, {9,1,2})
```

### 8.6 年飛星公式（已驗證）

```python
def year_center_star(year):
    """流年紫白入中星。已對 2023–2027 驗算，並與 2024 年公開九宮圖全盤吻合。"""
    return ((11 - (year % 9)) - 1) % 9 + 1

def year_plate(year):
    return fly(year_center_star(year), forward=True)   # 年盤一律順飛
```

驗算結果：

| 西元年 | 干支 | 入中星 |
|---|---|---|
| 2023 | 癸卯 | 四綠 |
| 2024 | 甲辰 | 三碧 |
| 2025 | 乙巳 | 二黑 |
| 2026 | 丙午 | **一白** |
| 2027 | 丁未 | **九紫** |
| 2028 | 戊申 | 八白 |

等價寫法（心算用）：西元年各位數字相加 → 除 9 取餘（0 視為 9）→ 用 11 減之 → 超過 9 再減 9。
例：2026 → 2+0+2+6=10 → 10 mod 9 = 1 → 11−1 = 10 → 10−9 = **1**（一白入中）。

> **分界點**：主流以**立春**為界，非農曆年初一。詳見 §5 的分歧說明。

### 8.7 月飛星公式

```python
# 年支分三組，決定「正月（寅月）」的入中星，之後逐月逆行（每月 −1）
MONTH_START = {
    ("子","午","卯","酉"): 8,   # 正月八白入中
    ("辰","戌","丑","未"): 5,   # 正月五黃入中
    ("寅","申","巳","亥"): 2,   # 正月二黑入中
}

def month_center_star(year_branch, month_index):
    """month_index: 1=寅月(立春起) … 12=丑月。月盤逐月遞減。"""
    start = lookup(MONTH_START, year_branch)
    return ((start - (month_index - 1)) - 1) % 9 + 1

def month_plate(*a):
    return fly(month_center_star(*a), forward=True)   # 月盤亦順飛
```

> 月的分界用**節氣**（立春、驚蟄、清明…），不是農曆初一。

### 8.8 太歲 / 歲破 / 三煞（可程式化）

```python
BRANCH_DEG = {  # 十二地支各佔 30°，但太歲只取其中 15° 的本位山
    "子": 0, "丑": 30, "寅": 60, "卯": 90, "辰": 120, "巳": 150,
    "午": 180, "未": 210, "申": 240, "酉": 270, "戌": 300, "亥": 330,
}
BRANCH_MOUNTAIN = {  # 太歲方 = 年支同名的那一座山（15°）
    "子":"子","丑":"丑","寅":"寅","卯":"卯","辰":"辰","巳":"巳",
    "午":"午","未":"未","申":"申","酉":"酉","戌":"戌","亥":"亥",
}
BRANCHES = ["子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥"]

def tai_sui(year_branch):
    return BRANCH_MOUNTAIN[year_branch]                      # 太歲方

def sui_po(year_branch):
    i = BRANCHES.index(year_branch)
    return BRANCH_MOUNTAIN[BRANCHES[(i + 6) % 12]]           # 歲破 = 對沖 (+180°)

# 三煞：依三合局，煞在「局的對面」三個地支
SAN_SHA = {
    frozenset(["申","子","辰"]): ["巳","午","未"],   # 水局 → 三煞在南
    frozenset(["寅","午","戌"]): ["亥","子","丑"],   # 火局 → 三煞在北
    frozenset(["巳","酉","丑"]): ["寅","卯","辰"],   # 金局 → 三煞在東
    frozenset(["亥","卯","未"]): ["申","酉","戌"],   # 木局 → 三煞在西
}

def san_sha(year_branch):
    for group, sha in SAN_SHA.items():
        if year_branch in group:
            return sha          # 依序為 劫煞 / 災煞 / 歲煞

# --- 犯太歲關係 ---
CHONG = {b: BRANCHES[(i + 6) % 12] for i, b in enumerate(BRANCHES)}
HAI   = dict(zip("子丑寅卯辰巳午未申酉戌亥", "未午巳辰卯寅丑子亥戌酉申"))
PO    = {"子":"酉","丑":"辰","寅":"亥","卯":"午","辰":"丑","巳":"申",
         "午":"卯","未":"戌","申":"巳","酉":"子","戌":"未","亥":"寅"}
XING_GROUPS = [set("寅巳申"), set("丑戌未"), set("子卯")]   # 三刑
SELF_XING   = set("辰午酉亥")                              # 自刑

def fan_tai_sui(year_branch):
    out = {"值": [year_branch], "沖": [CHONG[year_branch]],
           "害": [HAI[year_branch]], "破": [PO[year_branch]], "刑": []}
    if year_branch in SELF_XING:
        out["刑"].append(year_branch)
    for g in XING_GROUPS:
        if year_branch in g:
            out["刑"] += sorted(g - {year_branch})
    return out

def no_digging(solar_year, year_branch):
    """動土禁忌方位＝太歲 ∪ 歲破 ∪ 三煞 ∪ 五黃宮"""
    ys = year_center_star(solar_year)
    return {"太歲": tai_sui(year_branch), "歲破": sui_po(year_branch),
            "三煞": san_sha(year_branch), "五黃宮": palace_of(5, ys)}
```

### 10.4 調研方法的限制（誠實揭露）

- **WebSearch 全域額度在調研中段耗盡（200/200）**。此後全靠 WebFetch 直抓已知 URL；
  各家備援搜尋引擎（DuckDuckGo、Bing、Mojeek、Ecosia、Startpage、Brave、百度、搜狗）
  在本環境全部觸發反爬或回傳無關結果。
  **§10.3 的「查無」有相當比例是額度耗盡導致的未竟查證，不等於確定不存在。**
  若要補查，需提高 `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` 後重跑。
- 中文一手資料的最大缺口是**知乎、百度文庫、每日頭條全站 403**，
  這也是《沈氏玄空學》《玄空秘旨》原文取不到的主因。
- 風水論斷（吉凶、化解物品、斷語）本質是**術數流派主張，不是可證偽的事實**。
  本文只保證「某來源確實這樣說」，不保證其有效性。
